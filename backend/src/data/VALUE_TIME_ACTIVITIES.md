## 💾 Database Schema

Data ini disimpan di collection **valuetimelists** dengan struktur:

```javascript
{
  _id: ObjectId,
  activity_code: String (unique),
  activity_name: String,
  category: "VALUE TIME",
  sub_category: "Corrective" | "Preventive" | "Pekerjaan Proyek MTC",
  standard_time: Number (dalam menit),
  unit: "minutes",
  description: String,
  status: "active" | "inactive",
  created_at: Date,
  updated_at: Date
}
```

---

## 🔍 Cara Menggunakan

### 1. Query semua Value Time activities
```javascript
const activities = await ValueTimeList.find({ status: 'active' });
```

### 2. Query berdasarkan sub_category
```javascript
const corrective = await ValueTimeList.find({ 
  sub_category: 'Corrective', 
  status: 'active' 
});
```

### 3. Query activity tertentu
```javascript
const activity = await ValueTimeList.findOne({ 
  activity_code: 'VT-COR-001' 
});
```

### 4. Search by name
```javascript
const results = await ValueTimeList.find({
  activity_name: { $regex: 'pisau', $options: 'i' }
});
```

---

## 📝 Catatan Penting

1. **Standard Time** adalah estimasi waktu normal untuk menyelesaikan pekerjaan
2. **Actual Time** bisa berbeda tergantung kompleksitas masalah
3. Mekanik harus memilih activity_code yang sesuai saat input OHE
4. Sistem akan memberikan warning jika actual_time >> standard_time
5. Semua activities berstatus 'active' dan dapat digunakan
